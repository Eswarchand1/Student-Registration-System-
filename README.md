# Student Registration System

## Overview
This is a simple web-based Student Registration System built with HTML, CSS, and JavaScript. It allows users to register students with their name, ID, email, and contact number. Users can also view, edit, and delete records. Data persists across page refreshes using localStorage.

## Features
- **Registration Form**: Input fields for student details with validation.
- **Display Records**: Table showing all registered students.
- **Edit/Delete**: Buttons to modify or remove records.
- **Validation**: Ensures correct data types (e.g., numbers for ID/contact, valid email).
- **Persistence**: Data saved in localStorage.
- **Responsive Design**: Works on mobile, tablet, and desktop.
- **Dynamic Scrollbar**: Vertical scrollbar added only when needed.

## Technologies Used
- HTML5
- CSS3 (with media queries for responsiveness)
- JavaScript (ES6+)

## How to Run
1. Download the files (`index.html`, `style.css`, `script.js`).
2. Open `index.html` in a web browser.
3. Register students, edit/delete as needed.

## File Structure
- `index.html`: Main HTML page.
- `style.css`: Stylesheet for layout and responsiveness.
- `script.js`: JavaScript for functionality and logic.
